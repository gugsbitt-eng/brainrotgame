Combinações

Use as setas do teclado (ou WASD) para mover os tiles. Cada fusão evoca mais um brainrot italiano.

Como jogar

  • Deslize os tiles para juntar brainrots iguais.
  • Depois de cada jogada aparece um novo delírio (2 ou 4).
  • Planeje os movimentos – quando não houver jogadas, acabou.
  • Chegue ao 2048 para coroar o brainrot supremo.

Controles adicionais

  • WASD ou ↑↓←→
  • Toque e arraste no celular
  • Pressione N para começar de novo
